## 🎯 Overview

**Alzheimer's AI** is a comprehensive decision-support application built to detect early signs of Alzheimer's disease from magnetic resonance imaging (MRI) brain scans. Utilizing state-of-the-art Deep Learning models (including Custom CNNs, ResNet50, EfficientNet, DenseNet, MobileNet, and Vision Transformers), the system classifies MRI scans into four distinct diagnostic stages while providing visual explainability through Grad-CAM heatmaps.

The project features a **FastAPI backend** for low-latency inference and PDF report generation, paired with a modern **React 18 + Vite frontend** styled with a custom **Glassmorphism UI design system**.

---

## 🚀 Key Capabilities & Features

### 🔍 1. Multi-Class Deep Learning Classification
Classifies structural MRI scans into 4 clinical Alzheimer's disease stages:
- **Non Demented**: Healthy brain tissue with standard hippocampal volume.
- **Very Mild Demented**: Early subtle changes, minimal cortical atrophy.
- **Mild Demented**: Moderate structural changes and ventricular expansion.
- **Moderate Demented**: Advanced tissue loss and pronounced atrophy.

### 👁️ 2. Explainable AI (Grad-CAM Visualizations)
- Generates **Grad-CAM (Gradient-Weighted Class Activation Mapping)** heatmaps.
- Highlights specific spatial regions in the brain MRI that influenced the network's prediction.
- Interactive **opacity blend slider** in the UI allows clinicians to layer heatmaps directly over original grayscale scans.

### 📁 3. Medical Image Processing Pipeline
- Supports standard medical and web image formats: **DICOM (`.dcm`)**, **NIfTI (`.nii`, `.nii.gz`)**, **PNG**, and **JPEG**.
- Automatic skull stripping / brain cropping, intensity normalization, resizing, and grayscale standardization.
- **Patient-Aware Data Splitting**: Guarantees slice data leakage prevention by partitioning datasets strictly by patient ID.

### 🎨 4. Modern Glassmorphism Web Interface
- Built with **React 18**, **Vite**, and **Tailwind CSS**.
- **Glassmorphic UI Elements**: Translucent backdrop-filtered cards (`blur(12px)`), glowing ambient highlights, smooth transitions, and high-contrast dark theme.
- Interactive dashboards with **Recharts** analytics, upload history tracking, and scan comparison tools.

### 📄 5. PDF Clinical Report Generation
- Powered by **ReportLab**.
- Generates downloadable clinical PDF summaries containing patient demographics, prediction confidence meters, side-by-side MRI & Grad-CAM visual overlays, model metadata, and disclaimers.

### 🔒 6. Security & Role-Based Access Control (RBAC)
- Secure **JWT Authentication** with bcrypt password hashing.
- Differentiates between **Clinician Users** (upload scans, view predictions, generate reports) and **System Administrators** (manage users, model registry, and audit logs).

## 💻 Quick Start & Setup Guide

### Prerequisites

Ensure you have the following installed on your system:
- **Python 3.11+**
- **Node.js 18+** & **npm**
- (Optional) **Docker** & **Docker Compose**

---

### Option 1: Local Development (Recommended)

#### 1. Clone & Prepare Virtual Environment

```bash
# Clone the repository
git clone https://github.com/your-username/alzheimers-ai.git
cd alzheimers-ai

# Create a Python virtual environment
python -m venv venv

# Activate virtual environment
# Windows (PowerShell / CMD):
.\venv\Scripts\activate
# macOS / Linux:
source venv/bin/activate
```

#### 2. Install Dependencies & Initialize Database

```bash
# Install Python packages
pip install -r requirements.txt

# Create environment configuration file
cp .env.example .env

# Seed initial database & administrative accounts
python scripts/seed_db.py
```

#### 3. Start the Backend API Server

```bash
# Run FastAPI server on port 8000
python -m uvicorn backend.main:app --port 8000 --reload
```
> Backend API will be active at: **`http://localhost:8000`**  
> Interactive Swagger API Documentation: **`http://localhost:8000/docs`**

#### 4. Start the Frontend Development Server

Open a **new terminal window** and run:

```bash
cd frontend
npm install
npm run dev
```
> Web Application will be active at: **`http://localhost:5173`**

---

### Option 2: Docker Compose Setup

To launch the entire application (PostgreSQL DB, FastAPI Backend, and React Frontend) using Docker:

```bash
cd docker
docker-compose up --build -d
```

- **Frontend App**: `http://localhost:3000`
- **FastAPI API Docs**: `http://localhost:8000/docs`

## 🔌 REST API Reference

Major backend API endpoints available at `http://localhost:8000`:

| Category | Endpoint | Method | Description |
| :--- | :--- | :--- | :--- |
| **Auth** | `/api/v1/auth/login` | `POST` | Authenticate user and receive JWT access token. |
| **Auth** | `/api/v1/auth/register` | `POST` | Register a new user account. |
| **Predict** | `/api/v1/predict` | `POST` | Upload MRI image file (`.dcm`, `.nii`, `.png`, `.jpg`) for classification & Grad-CAM generation. |
| **History** | `/api/v1/history` | `GET` | Retrieve past scan predictions and details for current user. |
| **Reports** | `/api/v1/reports/{prediction_id}` | `GET` | Generate and download ReportLab PDF report for a prediction. |
| **Dashboard** | `/api/v1/dashboard/stats` | `GET` | Retrieve aggregated disease statistics & system metrics. |
| **Admin** | `/api/v1/admin/users` | `GET` | List all users (Admin role required). |
| **Admin** | `/api/v1/admin/models` | `GET` | View model registry details and active model weight status. |
