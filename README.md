## 🚀 Key Capabilities

- **Deep Learning MRI Classification Pipeline**: Multi-class categorization into 4 disease stages:
  - `Non Demented`
  - `Very Mild Demented`
  - `Mild Demented`
  - `Moderate Demented`
- **Multi-Dataset Support**: Ingestion logic supporting ADNI, OASIS, AIBL, and Kaggle datasets.
- **Medical Image Reader**: Parses DICOM (`.dcm`), NIfTI (`.nii`, `.nii.gz`), PNG, and JPG.
- **Patient-Aware Data Split**: Prevents slice leakage across train/validation/test splits using patient metadata IDs.
- **Modular Model Registry**: Pluggable architecture supporting:
  - Custom Baseline Convolutional Neural Network (CNN)
  - ResNet50 Transfer Learning Backbone
  - EfficientNetB0
  - DenseNet121
  - MobileNetV2
  - Vision Transformer (ViT) Encoder
- **Explainable AI (Grad-CAM)**: Generates heatmaps highlighting anatomical brain regions driving model prediction confidence.
- **FastAPI REST Backend**: Secure JWT authentication, role-based access control (User vs. Admin), audit logging, and rate limiting.
- **ReportLab PDF Generation**: Automated clinical PDF report export with patient details, side-by-side MRI & Grad-CAM overlays, and disclaimers.
- **Modern React Frontend**: Glassmorphism UI, interactive opacity sliders for Grad-CAM, analytics dashboard (Recharts), and upload history.
- **Docker Compose Orchestration**: Containerized PostgreSQL, FastAPI backend, and React frontend.

## 💻 Quick Start & Installation

### Option 1: Local Development

```bash
# 1. Clone repository
git clone https://github.com/your-username/alzheimers-ai.git
cd alzheimers-ai

# 2. Setup Virtual Environment
python -m venv venv
# On Linux/macOS:
source venv/bin/activate
# On Windows:
venv\Scripts\activate

# 3. Install Python Dependencies
pip install -r requirements.txt

# 4. Copy Environment File & Seed Database
cp .env.example .env
python scripts/seed_db.py

# 5. Start FastAPI Backend Server
uvicorn backend.main:app --reload --port 8000
```

In a separate terminal window, start the React frontend:

```bash
cd frontend
npm install
npm run dev
```

Visit `http://localhost:5173` to access the web application.

---

### Option 2: Docker Compose Setup

```bash
cd docker
docker-compose up --build -d
```

- **Frontend Application**: `http://localhost:3000`
- **FastAPI REST API Docs**: `http://localhost:8000/docs`
